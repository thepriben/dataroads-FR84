Guide utilisateur

Carte web du réseau routier départemental du Vaucluse (84). Ce guide décrit les usages courants : afficher une couche, lire la carte, utiliser les outils. Prototype CD84 — données locales et sources ouvertes.

Interface générale

L'écran se partage en trois zones : l'en-tête (titre, météo, chiffres clés), la barre latérale gauche (légende et outils), et la carte. La légende défile à l'intérieur de la colonne ; la carte occupe tout l'espace restant.

Navigation sur la carte

  • Déplacer — clic maintenu + glisser, ou trackpad.
  • Zoomer — molette, pincement tactile, ou double-clic pour zoomer (double-clic avec Maj pour dézoomer).
  • Vue initiale — bouton maison dans la barre d'outils (coin supérieur droit de la carte) : recentre le Vaucluse au zoom par défaut.
  • Redimensionner la légende — glisser la barre verticale entre la légende et la carte ; double-clic pour revenir à la largeur par défaut.

Au chargement, seule la limite du département est visible : activez les couches dont vous avez besoin.

Contrôles de visibilité

Deux niveaux complémentaires :

  • Œil de rubrique (à droite du nom de famille, ex. 2/3) — affiche ou masque toutes les couches de la rubrique d'un coup.
  • Œil de couche (à droite du titre de section) — affiche ou masque une seule couche.

Cliquez sur le nom de la rubrique ou le chevron pour déplier / replier le contenu dans la barre latérale (sans changer la visibilité sur la carte).

Les pastilles grises sous chaque couche indiquent la fraîcheur des données (voir § Fraîcheur).

Rubriques et couches

Cartographie factuelle

Réseau, territoire et aménagements de base issus surtout d'OpenStreetMap.

Territoire — Limite du Vaucluse (84)

Toujours affichée. Contour en pointillés du département ; repère pour le cadrage.

Hiérarchie du réseau

Trois niveaux de routes départementales, chacun avec une couleur :

  • Rouge — réseau d'intérêt régional (ex. D900).
  • Orange — réseau de développement territorial.
  • Bleu — réseau d'intérêt local.

Comment : cliquez le titre Hiérarchie du Réseau ou chaque ligne pour activer un niveau. Les panonceaux de numéro de route apparaissent au zoom suffisant. Cliquez un tronçon pour une fiche (nom, surface, liens OSM / Wikidata).

Véloroutes

Itinéraires cyclables OSM (route=bicycle). Totaux en kilomètres : Via Rhôna (EV17), Méditerranée (EV8), Via Venaissia (V861), itinéraires locaux.

Comment : activer via l'œil de section. Les véloroutes structurantes sont mises en avant par la couleur.

Routes en construction

Tronçons tagués construction ou projet dans OSM.

Comment : activer la couche ; les tronçons s'affichent sur la carte. Compteurs dans la légende.

Villes principales

Chefs-lieux et grandes communes (centres + libellés).

Comment : activer la couche pour les repères toponymiques.

Données statistiques

Données historiques ou agrégées — à charger à la demande pour ne pas surcharger la carte.

Accidentologie

Accidents du millésime 2024 (BAAC), classés : mortels, blessés hospitalisés, blessés légers.

Comment : activer la couche ; cliquez un marqueur pour le détail (date, route, commune).

Stations de comptage

Stations CD84 (data.gouv.fr), classées par trafic : élevé (> 20 k véh/j), moyen, faible.

Comment : activer dans la légende ou via le bouton Comptages CD84 sur la carte (les deux restent synchronisés). Clic sur une station : MJA, part PL, année.

Temps réel

Signaux récents : météo et trafic annoncé.

Stations météo

Quelques stations du département (Open-Meteo). Données courantes : température, vent, humidité.

Comment : activer la couche ; cliquer un marqueur pour la fiche. Une station est aussi tirée au hasard dans l'en-tête.

Événements routiers (Bison Futé)

Travaux, bouchons, accidents en cours (flux DATEX II / Info Routière), filtrés sur la zone.

Comment : activer la couche ; icônes sur la carte, popup au clic.

Incubateur

Couches expérimentales : ouvrages d'art, environnement, biodiversité, webcams recensées.

Couche ponts

Ouvrages d'art OSM du département : tablier, culées, piles. Affichage adapté au zoom :

  • Zoom lointain — grappes (nombre de ponts ou de photos).
  • Zoom ≥ 14 — géométrie des éléments.
  • Zoom ≥ 16 — photos Panoramax / Mapillary le long de l'ouvrage.

Comment : activer la couche ; cliquer une grappe pour zoomer progressivement ; cliquer un pont ou une photo pour ouvrir la visionneuse (vue en plan schématique + photo principale). Les boutons Panoramax / Mapillary filtrent les sources photo.

Espaces naturels sensibles (ENS)

Polygones CD84 (DataSud). Superficie, communes, gestionnaire.

Comment : activer la couche ; cliquer un polygone pour la fiche.

Observations iNaturalist

Observations filtrées par intersection avec les ENS du 84.

Comment : activer la couche ; cliquer un point pour espèce, date, lien iNaturalist.

Webcams

Recensement manuel (incubateur) : trafic CD84 au carrefour de Bonpas, stations du Mont Ventoux (Mont Serein, Chalet Reynard).

Comment : activer la couche ; cliquer un marqueur pour la fiche et le lien vers le flux externe.

Outils & méta

Recherche, qualité des données, statistiques réseau, calendrier de mise à jour. Pas de couche carte supplémentaire (sauf panneau qualité).

Rechercher une route

Champ de recherche (ex. D900, D4) et liste filtrée. Clic sur une route : centrage carte, surbrillance, fiche dans Informations Route.

Qualité OSM / Wikidata

Résumé dans la barre latérale : couverture Wikidata, relations OSM. Bouton Panneau détaillé : panneau sur la carte (métriques, routes sans Wikidata, sans relation).

Informations réseau

Compteurs : nombre de routes, tronçons OSM, longueur cumulée, trafic MJA min/max, ponts, tunnels.

Formule de rafraîchissement

Calendrier par source (OSM, Wikidata, externe, nature, météo, statique) et état du dernier rafraîchissement.

Barre d'outils carte

En haut à droite de la carte :

  • Maison — vue initiale du département.
  • Comptages CD84 — active la couche stations de comptage (sync avec la légende).
  • Convois except. — met en évidence le réseau régional et territorial, atténue le local (aide au gabarit exceptionnel).
  • Limitations — colore les tronçons selon la vitesse max OSM ; au zoom ≥ 11, pictogrammes hauteur / poids sur ponts et passages remarquables.

Les boutons actifs sont soulignés visuellement (fond sombre).

En-tête

  • Logo — retour à l'accueil de l'application.
  • Chiffres clés — ouvre un panneau plein écran : indicateurs réseau (routes, trafic, véloroutes, qualité OSM, etc.). Fermer par × ou clic à l'extérieur.
  • Météo — un aperçu d'une station du département (température, conditions). Pour toutes les stations, utiliser la couche Stations météo.

URL et partage

L'adresse du navigateur se met à jour quand vous déplacez ou zoomez la carte et quand vous changez les couches visibles. Paramètres utiles :

  • z, lat, lng — zoom et centre.
  • ly — couches actives (codes courts : hr, ht, hl, ens, inat, wcam, bridges, etc.).
  • fam — rubriques entièrement ouvertes (optionnel si ly est précis).

Copiez l'URL pour retrouver la même vue après rechargement.

Fraîcheur des données

Sous chaque couche, une pastille indique quand les données ont été générées et quand le prochain rafraîchissement est prévu.

  • OSM (routes, véloroutes, communes, constructions, ponts) — mise à jour bi-hebdomadaire (workflow GitHub).
  • Externe (comptages, Bison Futé) — toutes les 3 h.
  • Nature (ENS, iNaturalist) — toutes les 3 h.
  • Météo — live navigateur, ~10 min.
  • Statique (limite 84, accidents 2024, webcams) — snapshot versionné, mise à jour manuelle.

Le détail complet est dans Outils & méta → Formule de rafraîchissement.
